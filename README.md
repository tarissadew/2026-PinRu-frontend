# PinRu Frontend - Web Application

### 📝 Deskripsi
Antarmuka pengguna (UI) untuk layanan PinRu yang memungkinkan pengguna melakukan eksplorasi ruangan, melakukan booking secara real-time, dan memantau status peminjaman(andmin).

### 🛠️ Teknologi
* **Framework**: React 18 (TypeScript)
* **Build Tool**: Vite
* **Styling**: Tailwind CSS
* **Icons**: Lucide React
* **State Management**: React Hooks (useState, useEffect)
